# The Rise of Serbia

Europa Universalis V mod targeting **1.4.6**.

Build a Serbian empire under Dušan and guide its successor through the political inheritance. Includes expanded conquest objectives, integrated vanilla coronation and Code events, situation UI cards, regional settlements, and two imperial outcomes.

**v0.1.0 is an untested-in-game prototype.** Static script checks and scenario evaluation passed; EU5 loading, UI rendering, and all-DLC interactions still need a playtest.

- [Installation, gameplay, compatibility, and testing guide](rise_of_serbia/README.md)
- [Mod source](rise_of_serbia)

Extract the ZIP and install its `rise_of_serbia` folder as a local mod. Start a new 1337 campaign as Serbia. Full instructions are in the guide.
